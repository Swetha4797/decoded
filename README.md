# Decoded

**Big concepts. Small explanations.**

Complex tech. Simply explained.

Decoded is a learning-in-public project that explains technical concepts through everyday analogies, original illustrations, and practical examples.

## Status

Initial repository foundation. The Next.js homepage implementation is being developed on a separate branch for review.

## Planned stack

Next.js, TypeScript, Tailwind CSS, and eventually Markdown/MDX for concept publishing.

## Development approach

Start small, verify each milestone, and keep the code accessible for a first AI-assisted software engineering project.
